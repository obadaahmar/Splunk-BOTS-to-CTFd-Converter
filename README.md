# Splunk-BOTS-to-CTFd-Converter
A Python script that merges and converts the Splunk BOTS questions, hints, and answers to a CTFd compatible importable CSV, including case-insensitive regex flag generation and JSON-structured hint integration with associated costs.

# How-to-use
Just download the script into the same folder where you unpacked your Splunk BOTS content (ctf_answers.csv, ctf_hints.csv, ctf_questions.csv) and run it :)

# CTFd Instructions
Please follow the official CTFd instructions on how to import the generated CSV file into the platform:
https://docs.ctfd.io/docs/imports/csv/#challenges
